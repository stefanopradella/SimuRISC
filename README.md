# SimuRISC

**SimuRISC** is a Simulink implementation of a RISC-V core, designed for easy autocoding into VHDL using HDL Coder.

## Features

- 32-bit RISC-V ISA CPU core
- Single-Cycle implementation
- *(WIP)* Support for Integer (I) extension
- Ready for HDL Coder code generation
- *(WIP)* Verified with [riscv-tests ](https://github.com/riscv-software-src/riscv-tests)
## Purpose

As an engineer familiar with MATLAB and Simulink, my main goal was to gain hands-on experience in designing a processor core. Additionally, I aimed to explore the capabilities and limitations of HDL Coder in this specific context. I believe that this approach to designing the core can be a valuable tool for teaching the principles of processor operation, supported by the intuitive visualization provided by Simulink.
## Environment Setup

Required MATLAB Add-Ons:
- Simulink
- HDL Coder

To compile, simulate and verify code execution an installation, the following software is needed:

- [RISC-V Toolchain]([https://github.com/riscv/riscv-gnu-toolchain]())
- [Whisper](https://github.com/chipsalliance/VeeR-ISS)

In this example, all the tools are installed under `/home/<user>/riscv`
##### To install the RISC-V Toolchain:
Install the required packages:cd ..
``` sudo apt install autoconf automake autotools-dev curl gawk texinfo bison flex libmpc-dev```

Then install the toolchain:
```
mkdir ~/riscv
export RISCV=/home/<user>/riscv
mkdir tmp
cd tmp

git clone https://github.com/riscv/riscv-gnu-toolchain
cd riscv-gnu-toolchain
./configure --prefix=$RISCV --enable-multilib
make
make install
```

After that, the compiler binaries will be available on `/home/<user>/riscv/bin`.
You can now add the binaries path to the PATH environment variable. Open the `~/.bashrc` file, and add the following line at the end of the file
```
export PATH="$PATH:/home/<user>/riscv/bin:home/<user>/riscv/riscv64-unknown-elf/bin"
```
##### To install the Whisper ISA Simulator:

```
sudo apt install libboost-all-dev
```
You can locate the boost directory path using the following command: `whereis boost`
After that, use the path in the following commands to install Whisper:
```
cd /home/<user>/riscv
git clone https://github.com/tenstorrent/whisper
cd whisper
make BOOST_DIR=<DIR>
```

Class `SimuRISC_Environment.m` contains the paths to the binaries of the required software. You should adjust them according to your actual environment.
## Test Runs

The `tests` folder contains both the test code and the scripts required to execute the tests sequentially. Each test is verified by comparing the results obtained from running the test on the Simulink model with the output generated by executing the same ELF file using the [Whisper](https://github.com/chipsalliance/VeeR-ISS) simulator. 

In the future, other simulators such as [Spike](https://github.com/riscv-software-src/riscv-isa-sim) may be supported for further verification.

The test scripts are organized as follows:
- `runBuiltinTests.m` runs the tests that are included with the project release. These are some basic tests to verify the main core features,they are not meant to be robust or extensive in any way.
- `runRISCVTests.m` runs the tests included in the  [riscv-tests ](https://github.com/riscv-software-src/riscv-tests) repository *(WIP)*
